# CLI 参考

```bash
quantserve list [keyword]          # 列出模型
quantserve download <model>        # 下载权重
quantserve quantize <model>        # 量化估算
quantserve plan <model>            # 并行规划
quantserve cost <model>            # 成本对比
quantserve serve <model>           # 启动服务
quantserve doctor                  # 环境诊断
quantserve init                    # 生成配置
```
